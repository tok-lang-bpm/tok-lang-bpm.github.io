Independent core

TokLang — Module
TokLang

The tok language in Julia. The independent core of the package (lexer, parser, canonical printer fmt and semantic BPMN 2.0 export semantic_xml) is a second implementation of the specification, checked against the conformance corpus in conformance/. TokLang.Engine gives the whole language through the Rust engine, TokLang.Sim the native simulator for large experiments and TokLang.Fit the calibration of simulation parameters on event logs.

TokLang.Diag — Type
Diag(code, line, id=nothing; arguments...)

A diagnostic of the independent core: its code (for example "P001"), the line of the document, the id of the element it concerns, or nothing, and the args of its message. message gives the text and severity the severity.
