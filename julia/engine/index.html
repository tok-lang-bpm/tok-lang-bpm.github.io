Engine

TokLang.Engine — Module
TokLang.Engine

The whole tok language through the Rust engine: the checker of every layer, canonical text, BPMN, SVG, DMN and form export, BPMN and DMN import, decisions and simulation. The functions mirror the Python package (tok.api) and the R package (tokr).

The shared library comes from the binary package tok_jll, a dependency of TokLang.jl. available tells whether it can be loaded on this platform. Errors of the engine are thrown as TokError.

Decisions and simulation

TokLang.Engine.eval_decision — Function
eval_decision(text, decision, values=Dict()) -> value

The value of a decision for the input values (tok eval). In a document of language 0.7 the decision is evaluated with everything it requires and the result is its value; in earlier documents the decision table alone gives a dictionary of outputs, a vector of them for hit policy collect, or nothing.

source
TokLang.Engine.simulate — Function
simulate(text; cases=nothing, seed=nothing, log=true, cases_table=true, xes=false,
         csv=false, lang="en") -> SimResult

Run the simulation of the Rust engine (tok sim). cases and seed override the attributes of simulate. xes=true adds the event log as XES (IEEE 1849-2016), csv=true the event log and the cases as the CSV text of tok sim --log and --cases-csv.

The result of simulate: kpi (the indicators of tok sim --json), report (the text tok sim prints), log (one dictionary per activity instance), cases (one per case), and on request xes, log_csv and cases_csv (otherwise nothing).

TokLang.Engine.sim_model — Function
sim_model(text; cases=nothing, seed=nothing) -> Dict

The simulation model of a document as the engine reads it: parameters of simulate, resources, variables, nodes with parsed distributions and timers, and sequence flows. The native simulator (TokLang.Sim) is built from it.

Command line and errors

TokLang.Engine.cli — Function
cli(args) -> Int

Run the tok command line of the engine with the arguments after the program name (cli(["sim", "model.tok", "--json"])) and return its exit status. The command writes to the standard output and error streams of the process.

source
TokLang.Engine.TokError — Type
TokError(kind, message, diagnostics)

An error reported by the engine. kind is one of "invalid_argument", "document" (the document has errors; diagnostics holds them), "render", "import", "unknown_decision", "decision", "feel", "distribution", "simulation", "io" and "internal".
